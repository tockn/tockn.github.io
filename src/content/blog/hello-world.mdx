## tockn.dev を作り直した

個人サイトを Astro + MDX で新しく作り直しました。

以前のサイトは Hugo + Introduction テーマで作っていましたが、6年ほど放置していたのでゼロからリビルドすることにしました。

### 技術スタック

- **Astro v5** — 静的サイト生成
- **MDX** — ブログ記事の執筆
- **Vanilla CSS** — スタイリング

### こだわりポイント

温かみのあるダークモードに、ミニマルクリーンなデザイン。余白をたっぷり取って、コンテンツに集中できるようにしています。

```typescript
const site = {
  name: "tockn.dev",
  framework: "astro",
  style: "warm-dark-minimal",
};
```

これから技術記事も書いていく予定です。
